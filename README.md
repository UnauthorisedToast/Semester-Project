For Players:

The build.bash file is to simply make the game compatible with linux. Windows users do not need to use it.


For Linux Users:
Run the commands as shown in the directory of the game folders:-
bash build.bash
./a.out

You may use the following command for ease and then just run "run"
alias run="build bash.bash && ./a.out"
